# ФІТ КНУ — сайт факультету

Самостійна робота № 2 «Знайомство з React», варіант 3 «Сайт факультету».
Адаптивний українськомовний сайт факультету інформаційних технологій КНУ імені Тараса Шевченка.

## Запуск

Потрібен Node.js 20.19+ або 22.12+ (перевірено на Node.js 24).

```bash
npm ci
npm start
```

Відкрийте адресу, яку Vite виведе в терміналі. Зупинка сервера — Ctrl+C.
У хмарному середовищі з недоступним домашнім кешем використовуйте `npm ci --cache /workspace/.npm-cache`.

```bash
npm run build    # production-збірка в dist/
npm run preview  # перегляд production-збірки
npm test         # браузерні перевірки
```

Тести використовують Chromium за шляхом `/usr/bin/chromium`. Для іншої системи задайте змінну `CHROMIUM_PATH` зі шляхом до встановленого Chrome/Chromium. Це потрібно тільки для тестування, для запуску сайту — ні.

## Сторінки

- `#/` — головна: вітальний блок, статистика, спеціальності, новини.
- `#/about` — опис, місія, мета, напрями підготовки та рівні освіти.
- `#/news` — новини з пошуком і фільтрацією за категоріями.
- `#/history` — історія створення та розвитку факультету.
- `#/news/:id` — повний текст обраної новини.

Маршрути на основі hash дозволяють розміщувати збірку на звичайному статичному хостингу без серверного перенаправлення маршрутів.

## Структура

```text
src/
  main.jsx                # підключення React, локальних шрифтів і стилів
  App.jsx                 # сторінки та маршрутизація
  styles.css              # стилі, адаптивність, hover/focus-стани
  components/
    Header.jsx            # логотип, навігація, мобільне меню
    Footer.jsx            # посилання та соціальні мережі
    NewsCard.jsx          # повторно використовувана картка новини
  data/
    faculty.json          # факультет, навігація, спеціальності, історія
    news.json             # новини та їхні повні тексти
public/images/            # локальні авторські SVG-ілюстрації
 tests/site.spec.js       # перевірки в реальному браузері
```

## Відповідність методичці

1. **React та JSX:** інтерфейс складається з функціональних компонентів; стан реалізовано через `useState`, обробку переходів — через `useEffect`.
2. **JSON:** дані імпортуються з `faculty.json` та `news.json`, списки виводяться через `.map()` зі стабільними ключами.
3. **Header:** спільний для всіх сторінок; пункти меню змінюють колір та отримують підкреслення під час наведення. Активна сторінка виділена.
4. **Основний контент:** спеціальності, статистика, описи факультету, історія та новини формуються з JSON.
5. **Footer:** містить навігацію, офіційний сайт та посилання на Facebook і YouTube.
6. **Адаптивність:** CSS Grid, Flexbox і media queries; мобільне меню, одна колонка на вузьких екранах, відсутність горизонтального переповнення.
7. **Додаткові блоки:** статистика, місія, навчальні напрями, хронологія, пошук і фільтри новин, окремі сторінки новин.

Замість застарілого Create React App з теоретичного прикладу використано Vite. Основні вимоги та принципи роботи React з методички збережено. Бекенд або хмарна база даних для цього варіанта не потрібні: дані містяться в JSON.

## Редагування даних

Щоб додати новину, додайте об’єкт до `src/data/news.json` з унікальним `id`, `category`, `title`, `excerpt`, `image` та масивом абзаців `body`. `date` — дата у форматі `YYYY-MM-DD` або `null`, якщо дата невідома. Ілюстрації розміщуйте в `public/images/`.

Інформацію про факультет і спеціальності змінюйте в `src/data/faculty.json`. Код компонентів для зміни тексту цих блоків редагувати не потрібно.

## Матеріали та застереження щодо змісту

Це навчальна інтерпретація сайту, а не офіційний ресурс факультету. Відомості про факультет та тексти новин взято з матеріалів користувача; актуальність оголошень слід звіряти з https://fit.knu.ua/. Історична дата заснування підтверджена наданим описом. Інші етапи хронології описують мету та діяльність без вигаданих дат.

Ілюстрації створені для проєкту й не є фотографіями корпусу. Шрифт Manrope постачається локально через `@fontsource/manrope`, іконки — Lucide. Сайт не потребує зовнішнього фотосервісу або Google Fonts. Посилання Facebook/YouTube ведуть на платформи: в матеріалах не було перевірених адрес офіційних акаунтів, їх можна замінити у `faculty.json`.

## Перевірено

`npm run build` та два сценарії Playwright: сторінки, JSON-картки, повний текст новин, пошук, фільтри, порожні результати, мобільна навігація, завантаження зображень, відсутність горизонтального переповнення. Скриншоти створюються в ігнорованій Git папці `test-results/`.
